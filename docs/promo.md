# DOCL 宣传文案

## 一句话版本

DOCL 是一个用 Rust 写的 Minecraft 启动器：安装包 4.5 MB，空闲时主进程只占 5 MB 左右内存，双击就能进来装版本、开联机、换皮肤。

## 短文案（发布页 / 群公告可直接用）

DOCL 是一个面向 Windows 的 Minecraft 第三方启动器，技术栈是 Tauri 2 + Rust + Vue 3。

和常见的启动器不同，它不把整个 Chromium 塞进安装包，界面复用系统自带的 WebView2，下载、校验、解压、启动这些重活全部由 Rust 后端完成。结果是安装包约 4.5 MB，空闲时主进程内存占用只有 5 MB 左右，冷启动几乎立刻出界面，不会出现"启动器比游戏还吃内存"的情况。

功能上它不只管启动：版本隔离、加载器安装、整合包导入导出、Modrinth / CurseForge 模组搜索、联机大厅、皮肤库与皮肤编辑器、崩溃诊断、模组更新检查、存档种子预览都在同一个窗口里。1.2.0 起 Forge / NeoForge 改由启动器自行安装，整合包导入后只占一个版本条目，删包即连带清理依赖。

界面走浅色木纹玻璃风，提供九套配色与六张内置底图，磨砂强度、圆角、密度、动效都能自己调。

下载：https://github.com/dawo4/DOCL/releases

## 长文案（论坛 / 专栏 / 介绍页）

### 先把话说在前面

启动器这个品类已经很拥挤了。DOCL 不打算在所有方向上都比谁强，它想解决的是两件具体的事：**别那么重**，以及**出了问题能看懂**。

### 技术栈：轻，是因为该省的都省了

DOCL 用 Tauri 2 构建，前端是 Vue 3 + TypeScript，后端是 Rust。

这意味着两件在传统启动器上很难做到的事：

- **不打包浏览器内核。** 界面跑在系统自带的 WebView2 上，安装包因此只有 4.5 MB 左右，不会动辄一百多兆。
- **重活交给 Rust。** 并行下载、文件校验、压缩包解压、JVM 进程管理、NBT 解析都在 Rust 侧完成，不经过 JS 桥接。

落到体感上，三个数字最直观：

| 指标 | DOCL |
| --- | --- |
| 安装包体积 | 约 4.5 MB |
| 空闲时主进程内存 | 约 5 MB |
| 冷启动到界面可操作 | 秒开 |

开着启动器去打游戏，它不会和游戏抢内存，也不会在后台拖慢整机。这点在 16 GB 内存的机器上尤其明显——大多数时候不是游戏不够用，是启动器先把内存吃掉了。

启动器该做的事它照样做全：内存自动按物理内存推荐、G1GC / ZGC 参数可切换、Java 运行时自动检测与安装、GPU 优先、启动前命令、逐版本独立参数。省下来的是开销，不是能力。

### 界面：木纹、玻璃、九个配色

界面是浅色木纹玻璃风，中文优先，所有文字按中文排版调过行高与字距，不是英文界面套了层中文翻译。

- 九套配色：纸木、青瓷、赤陶、月白、樱花、深海、香芋、夜墨、石墨
- 六张内置底图，也可以用自己的图片
- 磨砂强度、玻璃透明度、背景压暗、圆角、界面密度逐项可调
- 动效可以整体关掉

改完即生效，并且自动保存，不用找"应用"按钮。

### 功能：一个窗口里做完

**版本与启动**
原版与 Forge / NeoForge / Fabric / Quilt 安装，每个版本可以单独设置内存、Java、窗口尺寸、JVM 参数和启动前命令。多游戏目录切换、目录隔离都是内置的，不同版本之间不会互相污染模组和存档。

1.2.0 起，Forge / NeoForge 改由启动器自己安装：版本清单直接从安装器包内抽取，依赖走镜像下载，补丁在本地分步执行并校验。官方安装器遇到网络问题时会出现的「提示安装完成、启动即崩」不再复现。整合包导入后版本列表只保留整合包本身，被继承的原版和加载器不单独占条目，删除整合包时一并清理。

**下载中心**
游戏版本、加载器、整合包、资源包、光影、数据包统一在一个页面里，支持 BMCLAPI 与官方源切换，并发数可调。整合包支持 CurseForge / Modrinth / 通用 ZIP 导入，也能导出成 ZIP 和 `.mrpack`。

**社区资源**
Modrinth 与 CurseForge 搜索，自动按当前实例的游戏版本和加载器过滤，避免装上一堆不兼容的模组。已安装的模组还能检查更新。

**多人游戏**
联机大厅、局域网房间发现、服务器状态 ping、一键开服与服务器列表管理。

**皮肤**
账号皮肤与披风切换，本地皮肤库集中管理，内置皮肤编辑器支持 64x64 与旧版 64x32 两种规格。

**实例内容**
模组、资源包、光影、存档、截图、投影文件统一管理，支持拖入导入与启用禁用。

**诊断**
崩溃报告会被解析成能看懂的原因和处置建议，配一份完整的启动日志抽屉，不用再去翻 `.minecraft/logs`。

**存档种子预览**
直接读 `level.dat` 里的真实种子，一键跳到在线种子地图。

**设置中心**
分七个标签页：游戏与启动、Java 运行时、外观、性能与参数、下载、联机、更新。配置可以导入导出做备份。

### 1.2.0 更新了什么

- **版本列表改版**：卡片网格换成紧凑单行，图标可选 7 种预设，也能换成自己的图片
- **加载器安装内置化**：Forge / NeoForge 不再依赖官方安装器的联网流程，清单、依赖、补丁全部由启动器处理
- **整合包单条目**：导入后只显示整合包本身，删除时连带清理继承的原版与加载器
- **前置依赖自动补齐**：安装模组时解析 Fabric / Quilt / Forge 前置并自动下载
- **皮肤编辑器**：固定色板换成 HSV 取色器
- **导入与下载细节**：拖拽导入对话框、内容分类目录修正

### 关于更新

DOCL 提供自更新，但默认不打扰你。在「设置 → 更新」里选择清单来源即可：

| 来源 | 地址 | 适用 |
| --- | --- | --- |
| 国内加速（默认） | `https://cdn.jsdelivr.net/gh/dawo4/DOCL@main/update.json` | 国内网络 |
| GitHub 原地址 | `https://raw.githubusercontent.com/dawo4/DOCL/main/update.json` | 需要最快拿到新版 |

更新策略有「自动下载」「仅提示」「关闭」三档。更新时下载的是完整安装包，覆盖安装，不做差量补丁，避免装到一半的文件留下隐患。

### 下载与安装

- 下载：https://github.com/dawo4/DOCL/releases
- 系统要求：Windows 10 1809 及以上，需要 WebView2 运行时（Windows 11 已内置）
- 安装包暂未做代码签名，SmartScreen 可能提示「已保护你的电脑」，点「更多信息」→「仍要运行」即可
